Release 2026.10.02

PhoneAppDeck Android版を
Google Playでリリース

スマートフォンから、相談・実装・確認・リリースまで。アプリ開発の流れをひとつの場所で進めるための開発支援アプリ「PhoneAppDeck」のAndroid版を公開しました。

// Android now available

PhoneAppDeck

Google Playで見る

// overview

PCの前にいなくても、開発の続きを進める

PhoneAppDeckは、GitHub上のプロジェクトを中心に、AI開発サービスへの相談・実装依頼、コードやプレビューの確認、GitHub Actionsによるビルド、ストア公開までの流れをスマートフォンから扱うためのアプリです。

「コードを書く画面」だけをスマートフォンへ移すのではなく、開発中に何度も発生するサービス間の往復を減らし、次にやることが見える状態をつくることを目指しています。

// four areas

4つの領域で、開発の流れを整理

01 / HOME

ホーム

GitHub接続やAI、変更確認、ビルドなど、開発環境の準備状況と次のステップをまとめて確認します。

02 / DEVELOPMENT

開発

ChatGPTやClaudeで相談し、CodexやClaude Codeなどの外部AI開発サービスへ実装依頼をつなぎます。

03 / PREVIEW

確認

コード変更をスマートフォン上でプレビュー。単体UIやアプリ画面を確認し、次の修正へ進みやすくします。

04 / RELEASE

リリース

GitHub Actionsの実行状況や履歴を確認し、Android / iOSのビルドからストア公開までを支援します。

// platform status

Android版を公開、iOS版も審査中

Android版はGoogle Playで公開済みです。iOS版も同時期にApp Storeへ申請しており、現在Appleによる審査が進んでいます。

iOS版について：公開が確認でき次第、PhoneAppDeckの製品ページとニュースで改めてお知らせします。

// download

Google Playからダウンロード

Android端末をお持ちの方は、Google Playから無料でダウンロードできます。スマートフォン中心でGitHubやAI開発サービスを使っている方は、ぜひお試しください。
