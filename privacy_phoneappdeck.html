PhoneAppDeck

1. 本ポリシーについて

PhoneAppDeck（以下「本アプリ」）は、スマートフォンからアプリ開発を行うための開発支援アプリです。本ポリシーは、本アプリにおける利用者情報の取扱いを説明します。

本アプリ独自のユーザーアカウントや、氏名、メールアドレス、パスワードによる会員登録機能はありません。当方がこれらの情報を会員情報として独自に収集することも予定していません。ただし、お問い合わせフォームで利用者が任意に入力する情報、および本アプリに組み込まれる第三者SDKが取得・送信する情報は、この説明とは区別して取り扱います。

GitHub、OpenAI、Anthropicその他の外部サービスのアカウントは、各サービスの提供者が管理します。第三者サービスまたはSDKによる情報の取得であっても、本アプリを通じて行われるものは、本ポリシーならびにGoogle PlayのData SafetyおよびApp StoreのApp Privacyにおける申告の対象として、実際の実装と各事業者の仕様を確認します。

2. GitHub連携

本アプリは、利用者が許可したGitHubリポジトリで開発支援機能を提供するため、GitHub APIを利用します。GitHubとの接続には、Authorization Code Flow with PKCE（S256）を使用します。本アプリ独自のGitHubパスワード入力欄は設けず、認証はGitHubが提供する画面で行います。

本アプリは、許可された権限の範囲で、次の情報をGitHubから取得し、または利用者が指示した操作内容をGitHubへ送信する場合があります。

  • GitHubのユーザー情報
  • リポジトリ名およびリポジトリのメタデータ
  • ブランチおよびコミット情報
  • Pull Requestおよびコードの差分
  • GitHub Actionsのworkflow、実行状態、ログ、artifactに関する情報、および利用者が指示した実行要求
  • 機能の提供に必要な範囲のソースコード

GitHub APIへの認証済み通信は、原則として利用者の端末からGitHubへ直接行います。認証コードの交換およびアクセストークン更新時のみ、コンテネクトが管理するCloudflare Workerを経由します。このWorkerは認証コード、PKCE code verifier、refresh token等を交換処理のために一時的に取り扱いますが、GitHub認証情報を永続保存しない設計です。

GitHubのアクセストークン、refresh token、認証状態の確認に必要な情報は、Android KeystoreまたはiOS Keychainを利用する端末のSecure Storageに保存します。これらをlocalStorageや通常のPreferencesへ保存しません。GitHub連携を解除すると、本アプリ内に保存されたGitHub認証情報を削除します。

リポジトリ、ソースコードおよび差分は、表示、プレビュー、Pull Request確認その他の機能提供に必要な範囲で処理します。コンテネクトが運営するサーバーへリポジトリ全体を恒久保存する設計ではありません。

3. Codex・Claude等の外部AIサービス

Codex、Claude等は、OSが提供する安全なブラウザコンポーネントで各外部サービスのウェブサイトを開く方式を予定しています。本アプリは、OpenAIまたはAnthropicのアカウントのパスワード、AIサービス上の会話履歴、利用者がAIへ入力したプロンプト、およびAIサービス側のアクセストークンを取得・保存しない設計です。

ブラウザで表示した外部サービスには、利用者と当該サービスとの間で直接情報が送信されます。各サービスは、それぞれの利用規約およびプライバシーポリシーに従い、アカウント情報、入力内容、端末・ブラウザ情報、IPアドレス等を取り扱う場合があります。これらは外部サービス自身による取扱いであり、本アプリが直接取得する情報ではありません。

AIが作成したコード変更を本アプリで確認する場合、本アプリが取得するのは、GitHub等の連携先から表示に必要な範囲で取得したコードまたは差分です。

4. 端末内に保存するデータ

本アプリは、機能および設定を提供するため、必要な情報を利用者の端末内に保存します。

  • GitHubのアクセストークン、refresh token、およびOAuth認証に必要な一時情報 Android Keystore / iOS Keychainを利用するSecure Storageに保存
  • 選択中のリポジトリ、ブランチ、表示設定その他のアプリ設定
  • 広告表示判定に用いる回数、日付、最終表示時刻等 Capacitor Preferencesに保存
  • プレビューや操作状態など、機能提供に必要な端末内データ

端末内データは、アプリの設定や連携解除操作、端末の設定からのデータ消去、またはアンインストールにより削除できる場合があります。ただし、OSのバックアップ機能等により保持される場合があります。

5. 広告配信

本アプリは、広告配信のためGoogle AdMob（Google Mobile Ads SDK）を利用します。広告SDKは、本アプリの機能とは別に、利用者の端末から情報を取得し、Google等の第三者へ送信する場合があります。

Google PlayのData Safetyでは、Google Mobile Ads SDKの仕様および本アプリの設定に基づき、次のデータ種類を収集・共有するものとして申告しています。

  • おおよその現在地 IPアドレス等から推定される地域情報
  • アプリのインタラクション アプリや広告との操作情報
  • 診断情報 起動時間、ハング等、SDKやアプリの状態に関する情報
  • デバイスまたはその他のID 広告ID、App Set ID等

これらのデータは、広告・マーケティング、分析、不正行為防止・セキュリティ・コンプライアンスの目的で利用される場合があります。Google Mobile Ads SDKが送信するデータは、転送時に暗号化されます。

本アプリは、広告配信のために氏名、メールアドレス、電話番号、正確な現在地、メッセージ本文、写真・動画、音声ファイル、連絡先、カレンダー、財務情報または健康情報を独自に広告SDKへ入力する機能を提供していません。

広告配信に伴うデータの取扱いには、GoogleのプライバシーポリシーおよびGoogle Mobile Ads SDKの仕様が適用されます。本アプリの実装またはSDKの仕様を変更した場合は、Google PlayのData Safetyおよび本ポリシーを必要に応じて更新します。

6. ビルド・ストア公開支援と外部サービス

本アプリは、利用者が許可したGitHubリポジトリについて、GitHub Actionsのworkflowを表示・実行し、実行状態、ログ、成果物（artifact）等を確認する機能を提供します。これらの操作では、利用者のGitHub認証情報を用いてGitHub APIと通信します。

本アプリからGitHub Actionsを実行した場合、workflow名、対象ブランチ、入力値その他の実行要求がGitHubへ送信されます。実行後は、GitHubが保持する実行状態、ログ、artifact等を本アプリで取得・表示する場合があります。

Google Play Console、App Store Connect、TestFlight等への移動には外部サイトまたは各サービスの画面を利用します。各外部サービス上で利用者が入力・送信する情報には、それぞれのサービスのプライバシーポリシーが適用されます。

7. 分析・ユーザー投稿

本アプリ独自のユーザー行動分析またはプロフィール作成を目的とするFirebase Analytics等の分析SDKは利用していません。ただし、広告配信に使用するGoogle Mobile Ads SDKは、広告配信に関連する分析、不正行為防止等の目的で、前項に記載したデータを取り扱う場合があります。

本アプリ独自のSNS、作品投稿または公開プロフィール機能はありません。外部のX、Qiita、Zenn、GitHub等への共有リンクを提供する場合、共有操作後の情報は利用者と共有先サービスとの間で取り扱われ、本アプリの運営者が投稿コンテンツを保管するものではありません。

8. 第三者への送信・提供

当方が本アプリの機能を通じて取り扱う情報と、第三者サービスまたはSDKが取得する情報は区別されます。当方は、GitHub連携等で本アプリが取得する情報を、利用者が選択した機能の提供に必要な範囲で処理します。広告SDK等を導入した場合は、第三者事業者がSDKを通じて端末情報等を直接取得し、その事業者のサーバーへ送信することがあります。

本アプリは、GitHub連携、利用者が選択した外部AIサービスの表示、ビルド・ストア公開支援、広告配信等のため、必要な範囲の情報を各外部サービスへ送信する場合があります。送信先における情報の取扱いには、各事業者のプライバシーポリシーが適用されます。第三者による取得または送信であることのみを理由として本ポリシーの説明対象外とはせず、導入したSDKおよび実際の通信を確認して開示します。

コンテネクトは、法令に基づく場合、人の生命・身体・財産の保護に必要な場合、または利用者の同意がある場合を除き、取得した個人情報を機能提供と関係のない第三者へ販売または提供しません。

9. データの保存・削除

本アプリ独自のユーザーアカウントは作成しないため、本アプリのアカウント削除機能はありません。端末内に保存された本アプリのデータは、端末の設定から本アプリのデータを消去するか、本アプリをアンインストールすることで削除できます。ただし、OSのバックアップ機能によりデータが保持される場合があります。

GitHub、OpenAI、Anthropic、GoogleまたはApple等が保持するデータやアカウントの削除は、各サービスの設定および手続に従ってください。

コンテネクトが管理するCloudflare Workerは、GitHubの認証コード交換およびアクセストークン更新のため、認証コード、PKCE code verifier、refresh token等を処理しますが、これらのGitHub認証情報を永続保存しない設計です。今後、コンテネクトが運営するサーバーへ利用者データを保存する機能を導入する場合は、保存するデータ、目的、保存期間、保護措置および削除依頼方法を導入前に明記します。

11. 適用範囲・変更

本ポリシーは、本アプリにのみ適用されます。外部サービスには、各サービスが定める利用規約およびプライバシーポリシーが適用されます。

機能、利用するSDK・APIまたは法令等の変更に応じて、本ポリシーを変更することがあります。重要な変更がある場合は、本ページまたはアプリ内の適切な方法でお知らせします。
