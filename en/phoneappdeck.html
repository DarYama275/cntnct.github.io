// features

Your development flow, in one deck.

PhoneAppDeck is designed for the moments when you are away from a PC but still want to understand project status, review changes, and move development forward.

01

GitHub integration

Check repositories, branches, commits, pull requests, and GitHub Actions from your phone.

02

Run workflows

Follow workflow status and trigger supported GitHub Actions without switching to a desktop.

03

AI development services

Move between your project and supported external AI development services through a mobile-first workflow.

04

Review changes

Inspect code changes and diffs created during AI-assisted development while you are on the move.

05

TSX / JSX preview

Preview UI changes directly on mobile to understand the result before moving on.

06

Build & publish

Follow Android and iOS build status and continue toward store release from one workspace.
