// common topics

Quick help

GitHub connection

If a repository does not appear, confirm that the PhoneAppDeck GitHub App is installed for the account or organization that owns the repository and that the repository is included in the app's access settings.

Preview issues

Some projects cannot be previewed directly when their dependency graph or runtime requirements are outside PhoneAppDeck's supported preview environment. You can still use the repository and workflow features.

Builds and GitHub Actions

PhoneAppDeck displays and works with GitHub Actions workflows configured in your repository. If a build fails, open the workflow result and review the failing job or step for the underlying error.

Release workflow

Store submission and release steps may still require your Apple or Google developer account and the corresponding store requirements. PhoneAppDeck helps you continue the workflow from mobile without replacing those services.
