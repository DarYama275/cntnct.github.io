// planned features

開発を、ひとつのデッキに。

PCの前にいない時間にも、プロジェクトの状況を確認し、次のアクションへ進める体験を目指しています。

01

GitHub連携

リポジトリ、ブランチ、コミット、Pull Request、GitHub Actionsを確認。

02

Actions実行

workflowの状態を確認し、必要な処理をスマートフォンから実行。

03

AI開発サービス

CodexやClaudeなどの外部AI開発サービスを安全なブラウザで開く。

04

変更レビュー

AIが作成したコード変更や差分を、移動中でも素早く確認。

05

TSX / JSX Preview

UIの変更をプレビューし、実装のイメージをその場で確認。

06

Build & Publish

Android / iOSのビルド状態を確認し、ストア公開を支援。
